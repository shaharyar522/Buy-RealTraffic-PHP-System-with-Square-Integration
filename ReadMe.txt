
*****For Fresh Install******

4 easy steps to install ITWebTeam's Cash Randomizer.
1.Edit the db_connect.php file -enter your mysql database settings.
2.Edit the Config.php file
You can edit here the site look too.Also,you must edit the site paths(wwwroot,site url)
The config.php file contains the payment fees-so if you want to change them,you can do it there.
Also,from the config.php file you can switch on/off every payment processor.

Open the install folder and palce the database info in the connect.php

3.Upload all the files to your webserver.

4.Run /inastall/install.php file in your browser and follow the instructions .

After completing these steps go to www.YOURDOMAIN.com/radmin/index.php page and edit your payment settings.
The default password is:

username: admin
password: admin

You should change them as soon as possible and also delete the install.php page at the end.


Enjoy!
